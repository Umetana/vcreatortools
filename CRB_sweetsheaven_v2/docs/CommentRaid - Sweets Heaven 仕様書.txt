# CommentRaid - Sweets Heaven

## 概要

本プラグインは CommentRaid - IdolOnStage をベースとした派生ルールパックである。

コメントを「スイーツ（Sweets）」に変換し、
そのカロリー（kcal）を累積することで、
配信を視覚的に盛り上げる演出を提供する。

本プラグインはゲーム性を持たせることを目的とせず、
コメントを促進するための演出として設計されている。

---

## コンセプト

コメント → スイーツ化 → カロリー化 → 累積

・誰でも気軽に参加できる
・コメント内容による有利不利を極力排除
・ランダム主体の気持ちよさ重視

---

## ベース

以下のファイルを流用する

- idol_logic.js
- ui.html
- style.css
- plugin_manifest.js
- idol_config.js

---

## 廃止要素

以下は使用しない

- レベル（Lv）
- ステージ
- スキル
- 称号
- ボルテージ（VOLTAGE）

### スイーツ定義
SWEETS_MASTER = [
  { id: "macaron", name: "マカロン", emoji: "🍬", baseKcal: 200, variance: 0.3 },
  { id: "donut", name: "ドーナツ", emoji: "🍩", baseKcal: 320, variance: 0.3 },
  { id: "cake", name: "ケーキ", emoji: "🍰", baseKcal: 450, variance: 0.35 },
  { id: "parfait", name: "パフェ", emoji: "🍨", baseKcal: 700, variance: 0.4 }
]
スイーツ決定ロジック
基本はランダム
コメント長で軽くカテゴリ補正を行う（任意）

例：

短文：軽いスイーツ
長文：少し豪華なスイーツ

※ 完全な最適化を生まない設計とする

kcal計算
min = baseKcal * (1 - variance)
max = baseKcal * (1 + variance)
kcal = random(min, max)
文字数補正（軽微）
kcal += min(commentLength * 5, 120)

※ 上限あり（暴走防止）

### 本プラグインはゲームではない。

コメント内容による攻略・最適化を生まない設計とし、
ランダム性と視覚演出によって楽しさを提供する。
