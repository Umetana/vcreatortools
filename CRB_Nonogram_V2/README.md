# CRB Nonogram V2

`comment_raid_base_v2 v2.0.0` を相対参照する、10×10固定のコメント参加型ノノグラムです。

コメントは `FILL A3`（塗る）または `MARK B5`（×）の形式です。英字の大小は問いません。

管理UIから問題選択、投票開始・停止、即時締切、リセット、次／ランダム問題、1手戻すを操作できます。URLに `?admin=0` を付けるとOBS画面から管理UIを隠せます。

OBSの「対話」画面など、テンプレートがキー入力を受け取れる状態では、`P` キーで投票開始、`S` キーで投票停止を操作できます。入力欄や選択欄を操作中、キー長押し、実行できないフェーズでは反応しません。問題切り替えなどの破棄を伴う操作は、誤操作防止のため管理UIから行います。

右側の `RECENT` には、正解、不正解、無票の直近結果を最大3件表示します。詳細な投票履歴やユーザー情報は表示しません。結果や管理操作のメッセージは画面中央へ短時間だけ表示されます。

設定初期値は `config.js` で変更できます。途中経過はブラウザへ自動保存され、再読み込み時は未クリアなら `READY`、クリア済みなら `CLEAR` で復元されます。投票と残り時間は復元されないため、配信者が投票を再開してください。問題開始、問題リセット、次／ランダム問題では保存内容が新しい初期盤面へ置き換わります。

動作確認用として4問を収録しており、仕様上の公開目標20問は配信テスト後のコンテンツ拡充項目です。
